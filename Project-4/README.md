# AI Project 4 - OCR Text Recognition System

## Overview

This project implements an Optical Character Recognition (OCR) system using Python, OpenCV, and Tesseract OCR.

## Objective

The objective of this project is to recognize and extract text from images through image preprocessing and OCR techniques.

## Technologies Used

- Python
- OpenCV
- Pytesseract
- Tesseract OCR Engine

## Features

- Image Loading
- Grayscale Conversion
- Gaussian Blur for Noise Reduction
- Thresholding for Better OCR Accuracy
- Text Extraction using OCR
- Save Extracted Text to File

## Installation

```bash
pip install opencv-python
pip install pytesseract
```

## How to Run

```bash
python main.py
```

## Workflow

1. Load image using OpenCV
2. Convert image to grayscale
3. Apply Gaussian Blur
4. Apply thresholding
5. Extract text using Tesseract OCR
6. Save extracted text to a file
